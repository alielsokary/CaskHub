Features

Everything brew does, without the terminal.

CaskHub runs everything through your real brew binary — anything you install here can be managed from the command line, and vice versa.

Browse thousands of Mac apps

Curated shelves with a rotating hero pick, a Featured top 100, Recently Added, and every cask classified into browsable categories — Developer Tools, Productivity, Design, and more.

Top Charts, real install data

The most-installed casks ranked by Homebrew's public analytics, with 30, 90, and 365-day windows — see what the community actually uses.

One-click everything

Install, update, and uninstall with live progress states and cancellable downloads. pkg installers get a native macOS password prompt.

Adopt existing apps

Installed something from a DMG or another store? Bring it under brew management with one click — the app stays right where it is.

Updates that matter

Smart detection skips self-updating apps and normalizes packaging quirks, so the Updates badge only shows real updates.

Instant search

Search across names, tokens, and descriptions with ⌘F. Original app icons and rich metadata make results easy to scan.

Fully compatible with the CLI

CaskHub reads your real Caskroom and shells out to your real brew. It even detects apps you installed from the terminal, and walks you through installing Homebrew if it's missing.

Native & polished

Grid and list views, flexible sorting, light and dark themes, a custom design system — and bundled category data, so browsing never blocks on the network.

How it works

Three levels of Homebrew, one app.

Catalog & analytics

The catalog and install charts come from the public Homebrew API. No Homebrew installation is required just to browse.

Installed-app detection

CaskHub reads install receipts directly from your Caskroom — fast, offline, and no shelling out needed.

Real brew actions

Installs, updates, and uninstalls run through your actual brew binary, staying fully compatible with the command line.

Private by default

Anonymous, privacy-first analytics with IDs salted and hashed on-device. No personal data ever leaves your Mac, and you can opt out of everything in Settings → Privacy.

Free & open source

MIT licensed, built in the open with SwiftUI. No subscription, no premium tier, no ads — read the source or build it yourself.
